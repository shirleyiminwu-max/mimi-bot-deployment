## 📝 自訂事件說明

你可以編輯這個檔案來新增自己的重要日期：

### 範例格式：
```markdown
### 月/日（星期X）
- 🎂 **事件名稱**
  - 事件說明
  - 相關資訊
```

### 常用表情符號：
- 🎂 生日
- 💼 工作/會議
- ✈️ 旅行
- 🏥 醫療預約
- 📝 截止日期
- 🎉 慶祝活動
- 🍽️ 聚餐
- 📞 重要通話
- 🎓 學習/課程
- 💪 運動/健身
- 🛒 購物提醒
- 🔧 維修/保養

## 使用說明

### 編輯日曆
```bash
# 使用你喜歡的編輯器
nano ~/.openclaw/workspace/CALENDAR.md
vim ~/.openclaw/workspace/CALENDAR.md
```

### Mimi 如何使用日曆
1. 每天早上 6:00，Mimi 執行每日簡報
2. Mimi 讀取這個 CALENDAR.md 檔案
3. 檢查當天和未來幾天的事件
4. 在簡報中提醒你重要事件

### 提醒範例
**Mimi 的提醒訊息**：
```
📅 今日重要事件：
- 10:00 團隊會議（線上）
- 14:30 專案檢討

📌 即將到來：
- 明天（2/17）是美國總統日，聯邦假日
```

## 小提示 💡

1. **保持更新**：定期更新日曆，確保 Mimi 提供準確提醒
2. **清晰描述**：使用清楚的事件名稱和說明
3. **適度使用**：太多事件可能讓簡報變得冗長
4. **刪除過期**：定期刪除已過去的事件（或保留作為記錄）
5. **使用表情符號**：讓日曆更視覺化和有趣
